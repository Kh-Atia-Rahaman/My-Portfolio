# Kh. Atia Rahaman — Personal Portfolio Website

Welcome to my official portfolio repository! I am **Kh. Atia Rahaman**, a Computer Science & Engineering student at **Daffodil International University (DIU)**, specializing in **Artificial Intelligence Research**, **Deep Learning**, **Computer Vision**, and **Software Engineering**.

---

## 🌟 Portfolio Features

- 💎 **Modern Dark Obsidian & Lavender Aesthetics**: High-end UI with subtle glassmorphic elements and glowing accents.
- 🖼️ **Dedicated Hero Showcase**: Featuring high-resolution profile portrait, status badges, and social links.
- 🎓 **Academic & Research Focus**: Deep Learning, Computer Vision (PyTorch, OpenCV), Natural Language Processing (TensorFlow, Pandas), and Data Analytics (SQL).
- 🛠️ **Categorized Technical Arsenal**: Visual brand icon grid covering languages, frameworks, and developer tools.
- 📊 **Interactive Category Filter**: Filter research projects by Computer Vision, NLP, or Data Science.
- 📱 **100% Mobile Responsive**: Touch-friendly glassmorphic drawer navigation, fluid typography (`clamp()`), and responsive layouts.
- 📋 **Micro-Interactions**: Real-time top scroll progress bar and 1-click email copy widget.
